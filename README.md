# C Day 93 - Inventory Sales and Stock Alert System

## About
A C-based inventory application that manages product stock, processes sales, and displays low-stock alerts.

## Features
- View inventory records
- Sell products
- Automatically reduce stock after sales
- Calculate sales bills
- Restock products
- Search products by ID
- Display low-stock warnings
- Save updated inventory in a text file

## Files
- `inventory.c` - Main program
- `products.txt` - Sample product data

## How to Run
Compile:

`gcc inventory.c -o inventory`

Windows:

`inventory.exe`

Linux:

`./inventory`

## Data Format
`ID Name Quantity Price`

Product names must be single words.

## Concepts
Structures, arrays, functions, file handling, searching, calculations, and conditional logic.
